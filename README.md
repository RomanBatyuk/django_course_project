# django_course_project

## Описание:

django_course_project - веб-приложение, которое позволяет пользователям управлять рассылками сообщений для клиентов.
Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок,
а также отправки сообщений по требованию.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/RomanBatyuk/django_course_project
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте проект в PyCharm.
2. Теперь вы можете поучавствовать в учебном процессе ;)
